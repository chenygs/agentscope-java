🔄 call() 生命周期

1输入 agent.call(UserMessage, RuntimeContext)
2onAgent → 加载AgentState → 拼SystemPrompt
3ReAct Loop: onReasoning → onSystemPrompt → onModelCall → LLM → onActing(权限→工具) → 继续/退出
4保存 AgentState → Session + 后台维护
