🥚 单智能体（Demo 级）

最简可用的智能体，只需 3 个核心概念：Agent + Model + Memory

Agent 智能体
接收消息 -> 推理 -> 回复。最核心的抽象，所有智能体的基类。
ReActAgent / AgentBase
Model 模型
对接大语言模型的接口。内置 5 种实现：通义千问、OpenAI、Claude、Gemini、Ollama。
DashScopeChatModel / OpenAIChatModel
Memory ⭐ 记忆（7种实现）
记录对话历史。支持 InMemory、JSON 文件、Redis、MySQL、Mem0 等 7 种存储方案。
InMemory / Redis / MySQL / JSON / Mem0

🧠 复杂智能体

叠加工具、钩子、技能、知识库、中间件、权限六大能力

Tool 工具系统
@Tool + @ToolParam 注解定义工具，让 Agent 能做事。
Toolkit / @Tool / @ToolParam
Hook 钩子系统
在 Agent 生命周期各阶段插入逻辑：日志、鉴权、审计、过滤。
Hook / HookEvent
Skill 技能系统
提示词+工具+示例的组合包。支持自学习闭环。
SkillRegistry / SkillGitRepository
RAG 知识库
检索增强生成，减少幻觉。5 种实现。
Knowledge / GenericRAGHook
Middleware 中间件链
Agent 执行管道，五阶段模型。Harness 内置 13 个。
MiddlewareChain / MiddlewareBase
Permission 权限引擎
ALLOW/ASK/DENY 三态决策。保护危险操作。
PermissionEngine / PermissionMode

👥 多智能体联合

从 Pipeline 编排到 SubAgent 委派，从 A2A 跨服务调用到 Higress 企业网关

Pipeline 顺序/并行编排
SequentialPipeline / FanoutPipeline，支持嵌套。
SequentialPipeline / FanoutPipeline
SubAgent 子智能体
主 Agent 动态创建子 Agent 委派任务。
SubAgentTool / SubAgentDeclaration
A2A 跨进程协议
Agent-to-Agent 协议，跨进程/跨机器调用。
A2AClient / A2AServer
Higress+Nacos+RocketMQ
企业级基础设施集成。
Higress / Nacos / RocketMQ
